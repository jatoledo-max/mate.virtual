# mate.virtual — Soluciones digitales

Sitio web de **mate.virtual**, una mini agencia que ofrece servicios digitales para emprendedores: desarrollo de sitios y landings, y acompañamiento desde el concepto hasta el producto final.

## Contenido

- Presentación y servicios digitales para emprendedores.
- Proyectos recientes.
- Proceso de trabajo: del concepto al producto.
- Formulario de contacto para arrancar un proyecto.
- Modo claro y modo oscuro.

## Uso

Es un sitio estático de una sola página. Abre `index.html` en el navegador para verlo.

## Tecnologías

HTML y CSS, con las fuentes Syne y DM Sans de Google Fonts.
